# Jisho 1.0.1

Офлайн-приложение японского языка для обычного Xiaomi Smart Band 10. Круглая иконка с книгой, тёмный интерфейс, крупная кана и доступная кнопка «Назад».

## Обновление интерфейса 1.0.1

Кнопки действий увеличены с 44 до 60 единиц, стрелки — до 56, отдельная кнопка «Назад» — до 52. Между кнопками 8 единиц. На экране по два крупных действия. Списки уроков и тем листаются стрелками. Основной текст увеличен с 18 до 20, японский — с 26 до 28; крупный режим — 24 и 32.

В словаре одна запись на страницу или несколько связанных страниц. На продолжении повторяется японское слово; строки распределяются равномерно, обрывок перевода не остаётся без контекста. Текст переводов сохранён полностью. Переключатели настроек остаются на текущей странице после нажатия. Для ускорения перелистывания страницы урока рассчитываются один раз до смены настроек, а неизменившиеся кнопки и строки не пересоздаются. Свайпы в центре листают и словарь; в карточках они листают только текст, не показывают ответ и не выставляют оценку.

Устанавливай обновление поверх Jisho 1.0.0, не удаляя приложение. Имя пакета и исходный ключ подписи сохранены, versionCode повышен до 2. Формат сохранений совместим с 1.0.0. Позиция словаря восстанавливается по записи; разбиение на страницы может измениться.

## Установка

Готовый подписанный пакет: [jisho-1.0.1.rpk](results/jisho-1.0.1.rpk).

Перенеси файл на Android. В уже настроенном установщике приложений браслета выбери локальный RPK. Для Notify for Xiaomi разработчик описывает путь **Device → Third party app → выбор RPK**. После передачи открой **Jisho** в меню браслета. [Инструкция разработчика Notify](https://www.mibandnotify.com/xiaomi-mi-band/notify-xms-app-instructions.php).

Если пользуешься Mi Fitness со вкладкой Apps, используй импорт локального RPK, когда он доступен в твоей версии. Разработческая сборка Mi Fitness имеет отдельный путь **Me → About → Debug → Third-Party Apps → Install third app**; обычная версия может его не иметь. [Документация Xiaomi](https://iot.mi.com/vela/quickapp/en/guide/other/faq.html).

Это release-пакет, собранный AIoT-toolkit и подписанный локальным ключом. Нативный запуск проверен в эмуляторе Vela 4 при 212×520. Установка предыдущей версии 1.0.0 на физический Band 10 подтверждена фотографиями владельца. Новая версия 1.0.1 проверена в эмуляторе; обновление на физическом браслете пока не проверено.

## Что внутри

- 25 уроков Minna no Nihongo I: 1071 словарных записей, русский и узбекский переводы, кана и ромадзи.
- Словарь в порядке книги: перевод виден сразу, каждая запись показывается отдельно, длинные делятся на страницы с повторением контекста. Имена и названия доступны отдельно.
- Проверка в направлениях «перевод → японский» и «японский → перевод». Ответ открывается кнопкой; затем доступны «Знал» и «Не знал».
- Случайный проход без повторов, итог, точный список ошибок, повтор ошибок и последний результат отдельно для каждого урока и направления.
- 121 грамматическая тема с объяснениями на двух языках и авторскими японскими примерами с чтениями.
- Хирагана, катакана, особенности чтения, частицы, группы и формы глаголов, счётные суффиксы.
- Числа, цены, часы, минуты, месяцы, дни месяца, дни недели, длительности, возраст и количество. Просмотр и карточки используют общий движок.
- Независимые переключатели кандзи и ромадзи, три режима перевода, обычный и крупный текст. Кана остаётся видимой всегда.

Телефон и интернет для обычной работы приложения не нужны. Аккаунтов, рекламы, аудио и телеметрии нет.

## Как пользоваться

В главном меню шесть разделов. Кнопка «Ещё» показывает следующую группу действий. Стрелки «←» и «→» листают учебные страницы; «Назад» под ними возвращает к родительскому экрану. «Раньше» возвращает предыдущую группу действий. Основные действия доступны кнопками. Свайпы вверх/вниз в центральной области дополняют перелистывание словаря, правил и справочника; они не оценивают карточки и не подменяют системный выход.

Незаконченная проверка сохраняет порядок карточек, позицию, оценки и открытую сторону. При входе выбери «Продолжить». Новый проход требует подтверждения замены незаконченной сессии. Результаты пройденных наборов сохраняются отдельно; повтор ошибок не стирает исходный итог.

После оценки и смены настроек выполняется запись. Если она не удалась, приложение сообщает об ошибке. Повреждённое сохранение не сбрасывается молча: предлагается резервная копия либо подтверждённый новый старт.

## Предпросмотр на компьютере

Нужен Node.js 24.19.0. В папке проекта:

```powershell
npm ci
npm run preview
```

Открой [локальный предпросмотр](http://127.0.0.1:4173). Он использует ту же логику карточек, навигации и сохранений, что и приложение. Прогресс браузера и браслета хранится раздельно.

В архиве `JISHO_PREVIEW.zip` уже лежит собранная версия: распакуй и выполни `node serve.cjs`. Для её запуска установка npm-пакетов не нужна.

## Сборка и тесты

```powershell
npm ci
npm test
npm run validate
npm run build
```

RPK появится в `dist`. Учебные данные и шрифт уже включены, поэтому PDF и Python для обычной повторной сборки не требуются. Первый запуск сборки создаёт собственную пару подписи в `sign/`. Для обновлений уже установленной версии нужно сохранять исходную пару; закрытый ключ не включён в архив исходников. Не удаляй приложение перед обновлением, если нужен прогресс.

Для повторной подготовки учебных данных нужен исходный PDF и Python-пакет PyMuPDF. Пути к PDF заданы в `tools/import_sources.py` и `tools/extract_candidates.py`. Команда `npm run prepare:data` использует уже извлечённые кандидаты, проверенные переводы и журнал исправлений. Она не выдаёт новое автоматическое извлечение за проверенную базу.

Для изменения шрифта: `pip install -r requirements-assets.txt`, затем `npm run assets`. Шрифты Noto загружаются только при подготовке ресурсов на компьютере; приложение использует локальный поднабор с приложенными OFL-лицензиями.

## Виртуальная проверка

```powershell
node tools/run-emulator.cjs
node tools/native.cjs deploy
npm run test:native
```

Эти команды используют найденный SDK из `C:/Users/Luck1y/Desktop/Game Mi Band`. Для Jisho создаются отдельный виртуальный аппарат, отдельная копия образа, порты 8564/5593 и отдельные тестовые сохранения. Код, сборки и ключи игры не меняются. В другом окружении путь к установленному SDK задаётся в `tools/run-emulator.cjs`, а путь к ADB — в нативных тестовых инструментах.

Нативный тест очищает только сохранения Jisho внутри тестового эмулятора. Он проверяет словарь, настройки, три письменности, крупный текст, центральный свайп, открытие ответа, оценку и восстановление после полной перезагрузки гостевой ОС. Итоговое состояние карточки сравнивается по снимкам экрана.

Браузерная проверка: запусти `npm run preview`, затем в другом терминале `npm run test:ui`. При отсутствии Chromium сначала выполни `npx playwright install chromium`.
