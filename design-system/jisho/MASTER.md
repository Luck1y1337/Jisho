# Jisho — интерфейс браслета

Применён ui-ux-pro-max: design-system `language learning wearable minimal`; уточнение style `minimalism compact readable`; ux `gesture alternative predictable back`. Первый результат (Claymorphism, Hero/Testimonials/CTA, веб-шрифты) отклонён: это сайт, а не учебный интерфейс браслета. Приняты Minimalism & Swiss Style, предсказуемый возврат, кнопочная альтернатива жестам и отсутствие перехвата системных свайпов.

Иконка: круг с прозрачными углами, спокойный зелёный фон, контрастный геометрический разворот книги. Внутри круговой маски нет мелкого текста. Шрифт платформы пока проверяется диагностическим экраном. Локальные системные шрифты Windows не распространять в пакете. Браузерное отображение японского не доказывает поддержку браслетом.

## Поведение

Шесть вертикальных разделов меню; при нехватке места — кнопочная пагинация. Перевод в словаре виден сразу. До показа ответа оценка недоступна. Жесты только в центральной зоне и только как дополнение; экран карточки свайпом не оценивается. Системный возврат совпадает с кнопкой. Запись состояния после каждой оценки и смены настройки. Ошибка записи видна; резервное состояние восстанавливается по явному действию.

Контроль перед поставкой: references/pro-rules.md прочитан. Веб-рекомендации hover, Google Fonts, GSAP, ARIA не переносятся в Vela. Проверки касаний, системных жестов, физических шрифтов и безопасных областей требуют устройства и пока не пройдены.

## Обновление 1.0.1 по фотографиям устройства

Точечные запросы ui-ux-pro-max: `touch target compact navigation` (приняты Touch Target Size и Touch Spacing), `orphan heading line balance` (принят принцип баланса строк, веб-CSS не переносится в Vela). В Vela нет подходящего стека в базе навыка, поэтому реализация проверяется по документации платформы и в её эмуляторе.

По два действия высотой 60, между ними 8; стрелки 86×56 и отдельный возврат 140×52. Общая высота остаётся 520, поля 26/28/16. Чтение получает больше места при меньшем количестве действий. Точная геометрия общая для preview и Vela: src/shared/presentation.js. Размеры — единицы designWidth, не универсальные dp.

Контекст длинной записи повторяется на каждой странице. Все строки сохранены; последняя часть сбалансирована, нет страницы из одного хвоста перевода. Короткие записи не смешиваются. Размеры основного текста 20/24, японского 28/32, интерлиньяж 32/36. Длинные подписи кнопок явно переносятся максимум на две строки, заголовки подбирают размер до двух строк. После изменения настройки текущая группа действий сохраняется. Синтетические касания эмулятора проверяются отдельно от программных действий контроллера. Свайп карточки не раскрывает ответ и не оценивает его.

Фото владельца подтверждают установку 1.0.0 и показывают неудобства прежней компоновки. Проверка 1.0.1 на физическом устройстве ещё не выполнена. Перед выдачей повторно прочитан pro-rules.md; тема только тёмная, платформенные возможности screen reader и Dynamic Type не заявлены.

Компоновка текущего словаря кэшируется в единственном экземпляре и сбрасывается при смене урока/настроек. Vela не пересоздаёт неизменившиеся строки и кнопки при сохранении. Верхние заголовки ограничены шириной 160, длинное название «Обычные отрицательные формы» показано как «Обычные отрицания»; содержание темы сохранено полностью.
